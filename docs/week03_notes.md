Week 03 — CourseHub API

Nội dung thực hiện

Xây dựng REST API bằng FastAPI.
Kết nối cơ sở dữ liệu PostgreSQL.
Sử dụng Pydantic schemas để kiểm tra dữ liệu.
Kiểm thử API bằng Postman với collection và environment.

Kết quả

Hoàn thành và kiểm thử các request API.
Xử lý các trường hợp tạo dữ liệu trùng lặp, dữ liệu không hợp lệ, xóa dữ liệu và không tìm thấy tài nguyên.
Lưu mã nguồn và file Postman trên GitHub.

Bài học rút ra

Hiểu quy trình xây dựng, kết nối và kiểm thử REST API, đồng thời sử dụng Git để quản lý mã nguồn.
